Network Configuration Instructions

To route system traffic through DNSentinel:

  1. Buka Windows Network Settings → Properties adapter aktif → IPv4.
  2. Set Preferred DNS ke 127.0.0.1 dan Alternate ke 1.1.1.1.
  3. Buka Terminal/CMD sebagai Administrator dan jalankan ipconfig /flushdns.
